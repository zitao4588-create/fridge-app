- 隔离和删除采用可恢复状态：隔离后中断、移除源文件时失败、源文件已经移除但状态未回写、最终删除后状态未回写，下一轮都能从 `recoverySourcePending` 和已记录 `fileID` 继续。只有明确的文件不存在才按幂等成功处理；权限、网络或未知错误一律进入 `cleanup_failed`，不能伪装成已清理。
- 云函数同一 `main` 入口已加入可信定时事件分支：只有 `Type=Timer`、有 `Time` 且没有小程序调用者 OPENID 时才执行固定每批 20 条的到期清理；客户端伪造定时事件会按无效 action 拒绝。日志只记录扫描、删除和失败数量，不记录文件路径、会话、家庭或用户标识。
- `imageCaptureSessions` 集合和 `captureImageSession` 云函数只存在于本地；未来若进入部署评审，集合必须为 `ADMINONLY`，且需单独验证定时触发、最小权限和真实删除证据。
- 因本轮不允许部署或修改正式配置，定时触发器仍未创建，真实云文件删除、24 小时周期和重复触发的云端证据仍为未验证；代码级窗口关闭不等于生产硬上限已经成立。
