# 冰箱小雷达 v3.0 双账号与真机验收清单

更新时间：2026-07-26

用途：验证 v3.0 本地 C2 发布候选的真实微信账号、真机、分享、加载、反馈和一图一件录入流程。本清单不构成上传体验版、提审或发布授权。

## 记录规则

- 状态只使用：`通过`、`失败`、`未验证`。
- 每项记录测试时间、设备类型、预期结果和实际结果；失败时记录页面、步骤和脱敏错误类型。
- 账号只写“账号 A / 账号 B”，不记录 OPENID、手机号、昵称或二维码。
- 家庭和邀请只写“测试家庭 / 当前邀请”，不记录家庭 ID、邀请口令或链接参数。
- 图片只记录样本类型、大小区间和结果，不记录完整云文件地址、OCR 原文或私人库存内容。
- 任何没有真实运行的项目必须保持 `未验证`。
